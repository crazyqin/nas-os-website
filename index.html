Core features

默认只开真正核心的能力。

不是把功能写满屏幕。默认 Core 开箱能管盘、共享、用户与健康；其余产品能力按需打开。

01

存储与卷

btrfs 卷 / 子卷 / 快照，统一 API /api/v1/storage/*，WebUI 与后端契约一致。

02

文件共享

SMB 与 NFS 为 Core 默认能力；WebDAV / FTP / SFTP 等可在 optional 面启用。

03

身份与安全

用户与权限、首次登录强制改密、生产 CSRF、默认监听本机，安全默认更稳。

04

Core 健康探针

/api/v1/system/health 聚合 Core 模块真实 Health()，失败即 unhealthy。

05

可选产品面

Docker、VM、相册、AI、备份、云同步等：设 modules.optional: true 再启用。

06

Extension · Lab

7 个 Extension 按列表加载；Lab 实验能力仅源码保留，不进入默认 nasd 热路径。

FAQ

常见问题Common questions

NAS-OS 适合谁？

适合想把迷你主机、旧电脑、家用服务器变成私有云的个人、家庭和小团队。

默认会装很多功能吗？

不会。默认只启用 Core（用户、存储、网络、SMB/NFS、系统健康）。Docker / 相册 / AI / 备份等需 modules.optional=true 或配置 extensions。

和群晖/TrueNAS 有什么区别？

NAS-OS 更强调开源、轻量、可自托管；架构分层诚实（Core / Extension / Lab），差异化能力如本地 AI、WriteOnce 等按需启用，而非默认全开。

最新版本是什么？

当前官网同步版本为 v3.24.3 Stable。详见 GitHub Releases 与仓库 README 的默认交付面说明。
