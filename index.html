常见问题

你可能想了解这些

NAS-OS 适合谁？

适合想把迷你主机、旧电脑、家用服务器变成私有云的个人、家庭和小团队——照片、影片、工作文件放在自己家里。

默认会装很多功能吗？

不会。默认只带日常最需要的：账号、存储、网络、文件共享和系统状态。相册、备份、容器等想用时在应用中心打开即可。

和群晖 / TrueNAS 有什么区别？

NAS-OS 更强调开源、轻量、自己部署。功能不默认全开，需要什么再加；适合喜欢简洁、可控的人，而不是一上来塞满应用市场。

最新版本是什么？

官网当前对应 v3.24.3 稳定版。下载与更新说明见 GitHub 下载页。
