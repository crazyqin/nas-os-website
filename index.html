常见问题

你可能想了解这些

NAS-OS 适合谁？

想把迷你主机、旧电脑或家里服务器变成「私有云」的个人、家庭和小团队——照片、影片、工作资料放在自己家里，而不是只能放在别人的云盘。

默认会装很多功能吗？

不会。默认只有最常用的：账号、存储、网络、文件共享和系统状态。相册、备份、容器等，想用时到应用中心打开即可。

和群晖、TrueNAS 有什么不同？

NAS-OS 开源、可自己部署，更偏轻量和可控。功能默认不堆满，需要什么再加；适合喜欢简洁、愿意自己掌控数据的人。

最新版本是什么？

当前稳定版本为 v3.24.6，最新已发布的安装包见 GitHub 下载页。
